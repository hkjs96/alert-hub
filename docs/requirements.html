10로드맵 & 열린 이슈

Phase내용상태
1 · MVP수신 5종 + dedup + 대시보드 + Slack + 보안/테스트✔ 완료 (푸시됨)
2a · 조직 마스터계층·인원·배정 모델 + 등록관리 골격✔ 완료 → 2a-rev: 정/부/멤버 폐기→순서 모델, 데이터 격리, IA 3메뉴(처리순서 신규·멤버관리 확장), 인라인 신규등록
2b · 알람↔조직 연결enrichment 스냅샷(순번 포함) · 대시보드 개편(다중토글/초기화/미매핑 토글·모달/담당 패널) · 상세(순번 스냅샷·변경 배지)✔ 완료
2c · 액션Ack/Resolve 버튼 + 이벤트 기록 · 1순위 통지 반영✔ 완료 (통지 반영은 2b에서 선행, ack 고착 규칙 추가)
3 · 사람 레이어이메일 채널 → 시간 기반 자동 에스컬레이션(1순위 미ack N분→2순위) → Twilio 전화/SMS. order 데이터가 그대로 입력LATER
열린 이슈 (v0.2에서 이관, 답 포함)
  • 계정 레벨 전용 순서 편집 UI — 보류: 재정의는 예외 케이스, 조직 관리 인라인으로 충분. 실사용 수요 확인 후.
  • 내부 엔지니어의 프로젝트/서비스 단위 매핑 — 모델은 이미 지원. 멤버 관리 토글은 고객사 레벨 숏컷일 뿐임을 문서·UI 문구로 명시.
  • 스냅샷 vs 현재 배정 불일치 — 채택: 상세에 "담당 변경됨" 배지(2b).
  • 순서의 의미 범위 — 2b/2c는 "표시+1순위 통지"까지. 시간 기반 자동 상향은 Phase 3으로 명시적 분리.
